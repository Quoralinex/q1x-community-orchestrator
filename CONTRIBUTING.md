# Contributing

Thank you for contributing to Q1X Community Orchestrator.

## Workflow

1. Open or reference an issue for material changes.
2. Work from a feature branch or fork.
3. Keep each pull request focused on one coherent change.
4. Add or update tests and documentation with the implementation.
5. Run the repository validation commands before requesting review.
6. Resolve review comments and required checks before merge.

## Governance

`main` is protected. Direct pushes, force pushes and branch deletion are not part of the normal contribution path. Maintainers merge accepted changes using squash merge.

## Contribution licensing

Because Quoralinex intends to offer separate commercial licences, external contributions require an approved contributor licence agreement (CLA) before they can be merged. Until the CLA process is published, maintainers must not merge third-party code that would prevent Quoralinex from licensing the combined work under the community and commercial licensing models.

Do not submit code you do not have the right to contribute.
