# @quoralinex/q1x-community-sdk

TypeScript reference SDK for Q1X Community Orchestrator public contracts.

The SDK is a convenience implementation; the JSON schemas in `@quoralinex/q1x-community-contracts` remain normative. Phase 1 exposes provider-neutral types plus the minimal `CapabilityAdapter` interface for discovery and execution.
