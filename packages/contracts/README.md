# @quoralinex/q1x-community-contracts

Normative JSON Schema 2020-12 contracts for Q1X Community Orchestrator.

The schemas under `schemas/v1/` are the protocol authority. The TypeScript exports provide shared contract IDs and adapter-kind constants for convenience.
