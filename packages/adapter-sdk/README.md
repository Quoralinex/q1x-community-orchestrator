# Q1X Community Adapter SDK

Public authoring and conformance helpers for third-party Q1X Community Orchestrator adapters.

This package is part of the `0.1.0-alpha.1` public-alpha line. It depends only on the public Q1X Community SDK and does not expose runtime databases, audit stores, browser sessions, desktop backends or private Q1X control-plane interfaces.

Community adapters are ordinary application code selected by the operator. Conformance does not make third-party code trustworthy, and this SDK does not sandbox arbitrary JavaScript modules.

See the repository documentation for the full authoring, registration, trust and compatibility guidance.
